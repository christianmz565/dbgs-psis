Este proyecto requiere la instalación de las siguientes herramientas\+:


\begin{DoxyItemize}
\item {\bfseries{GCC}}\+: Compilador de C++.
\item {\bfseries{CMake}}\+: Herramienta de construcción multiplataforma.
\item {\bfseries{Doxygen}}\+: Generador de documentación.
\item {\bfseries{TeX Live}}\+: Distribución de La\+TeX para generar documentación en PDF.
\end{DoxyItemize}\hypertarget{development_autotoc_md1}{}\doxysubsection{\texorpdfstring{Instrucciones de Instalación}{Instrucciones de Instalación}}\label{development_autotoc_md1}

\begin{DoxyEnumerate}
\item {\bfseries{GCC}}\+: Instalar \href{https://www.mingw-w64.org/}{\texttt{ Min\+GW-\/w64}} o \href{https://www.msys2.org/}{\texttt{ MSYS2}}.
\item {\bfseries{CMake}}\+: Descargar desde \href{https://cmake.org/download/}{\texttt{ cmake.\+org}}.
\item {\bfseries{Doxygen}}\+: Descargar desde \href{https://www.doxygen.nl/download.html}{\texttt{ doxygen.\+nl}}.
\item {\bfseries{TeX Live}}\+: Descargar desde \href{https://www.tug.org/texlive/acquire-netinstall.html}{\texttt{ tug.\+org/texlive}}.
\end{DoxyEnumerate}
